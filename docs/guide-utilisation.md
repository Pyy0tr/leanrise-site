# Leanrise — Guide d'utilisation du back office

## Première connexion — créer un compte GitHub

Le back office utilise GitHub pour s'identifier. Si vous n'avez pas encore de compte :

1. Aller sur **github.com**
2. Cliquer sur **"Sign up"**
3. Suivre les étapes (email, mot de passe, vérification)
4. Transmettre votre nom d'utilisateur GitHub à Pierre — il vous ajoutera comme collaborateur sur le projet

Une fois ajouté, vous recevrez un **email d'invitation** de GitHub. Acceptez-le avant de vous connecter au back office.

---

## Accès au back office

1. Aller sur **leanrise-coaching.com/admin**
2. Cliquer sur **"Login with GitHub"**
3. Lors de la première connexion, GitHub vous demande d'autoriser l'application → cliquer **"Authorize"**
4. Vous arrivez sur le tableau de bord

---

## Témoignages vidéo

Cette section gère les vidéos YouTube affichées dans la galerie de témoignages du site.

### Ajouter une vidéo

1. Dans le menu de gauche, cliquer sur **"Témoignages vidéo"**
2. Cliquer sur **"Vidéos YouTube"**
3. Cliquer sur le bouton **"Add videos"** en bas de la liste
4. Coller l'URL complète YouTube dans le champ, par exemple :
   ```
   https://www.youtube.com/watch?v=K3ftJJDlUg0
   ```
   ou
   ```
   https://youtu.be/K3ftJJDlUg0
   ```
5. Cliquer sur **"Save"** en haut à droite

### Supprimer une vidéo

1. Cliquer sur l'icône de suppression à droite du champ
2. Cliquer sur **"Save"**

### Changer l'ordre des vidéos

Les vidéos apparaissent sur le site dans l'ordre de la liste.
Utiliser les poignées de glisser-déposer (icône à gauche de chaque entrée) pour réorganiser.

## Photos de transformation

Cette section gère les photos du carrousel "Avant/Après".

### Ajouter une photo

1. Dans le menu de gauche, cliquer sur **"Photos de transformation"**
2. Cliquer sur **"Photos"**
3. Cliquer sur **"Add photos"**
4. Cliquer sur **"Choose an image"** et uploader la photo depuis votre ordinateur
5. Cliquer sur **"Save"**

**Format recommandé :** JPEG ou WebP, ratio portrait (ex. 800×1000 px), moins de 500 Ko.

### Supprimer une photo

1. Cliquer sur l'icône de suppression à droite de la photo
2. Cliquer sur **"Save"**

### Changer l'ordre des photos

Même principe que les vidéos — glisser-déposer pour réorganiser.

---

## Publication

Chaque fois que vous cliquez sur **"Save"**, le CMS enregistre la modification directement sur GitHub. Le site se met à jour automatiquement en **environ 1 minute**.

Vous pouvez vérifier que la mise à jour est bien en cours sur **vercel.com** (demander l'accès à Pierre si besoin).

---

## Problèmes fréquents

**Le site ne s'est pas mis à jour après une sauvegarde**
Attendre 2 minutes et rafraîchir. Si toujours rien, contacter Pierre.

**Le login ne fonctionne pas**
Vérifier que vous êtes connecté sur github.com avec le bon compte, puis réessayer.
Si vous n'avez pas encore reçu ou accepté l'invitation GitHub, le login sera refusé.
